# D21：实体卡片盒

左侧改为木质卡片盒与纸卡，右侧保留“卡片与关联的展开”。六张预置卡片根据当前四份语料的已提交正文编写，均以问题作标题，包含自己的理解、明确的引用理由和精确文档出处。

- 点击盒中露出的问题标题取卡；左上返回图标把卡片放回。
- “创建卡片”取出空白纸卡，填写问题、Markdown内容、材料出处与理由。“查看卡片”预览Markdown排版，“继续书写”返回编辑。
- “放入卡片盒”核对引用后保存；“取消”以炭化、燃烧边缘和火星动画丢弃草稿。
- 固定地址、选择性引用、明确理由分别以荧光底色标出当前卡片的URI、问题标题和引用理由。“意外关联”不触发操作。
- 文档引用在左侧同一尺寸区域读取PDF；返回继续阅读原卡。卡片间的notes链接取出另一张卡片。
- Escape返回卡片或将卡片放回；新卡草稿中Escape等同取消。系统减少动态效果和课件B低功耗模式关闭长动画。

## 地址与保存

每张卡片的入口为 `patchouli://notes/{uuid}.md`。六张预置卡使用源码中的固定UUID；新卡创建时只生成一次UUID，放回、重排、切换页面与刷新均不改号。新卡保存在浏览器localStorage的 `week04-cardbox-v1`，不写入SQLite。下载Markdown保留UUID文件名、固定入口、正文、引用及理由。

出处格式为 `patchouli://texts/{document_uuid}/page-{PDF页序}.md?rev={revision_uuid}&box={box_uuid}`。页序从1开始。放入新卡时要求文档、页、已提交修订、文本块均能解析，引用理由不能为空。正文中的额外texts和notes链接也必须可解析。

超过八张卡时可浏览前后组，同一盒中所有卡片仍可取得。

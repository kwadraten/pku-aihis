# 新语料本地检索与出处回查验收

本次在原 PR #5 上补齐导入兼容问题后，使用真实 Chrome、本机 MiniLM 和 Qwen3 完成验收。
逐项结果、版本、查询、命中编号与耗时见 [浏览器运行记录](corpus-runtime-verification.json)。
验收覆盖新语料的 D01、D07–D13 流程；不把外部应用原有数据库的结果记作新库结果。

## 结论与修复

2,686 条公开论文与电子书切块、242 条仅本地论坛白名单均可导入；检索命中能回查出处。
原 JSONL 是纯文本包，只支持关键词、全文等不依赖向量的功能。现提供独立的本地向量准备脚本，
本机已为全部 2,928 条逐条实际计算配套向量，保留原有全部字段，新增向量及正文 SHA-256。
生成文件和论坛正文不随本 PR 公开。

本次修正三个实际兼容问题：

1. 纯文本包进入向量页时，只出现嵌入配置错误。现在 D01 显示可用功能，向量页明确提示导入配套 JSON。
2. 来源卡片和候选列表仅按旧史料显示 PDF 页码。现在优先显示真实 `locator`，并附作者、片段编号、字符位置、来源页面和本地核验原件入口。
3. 回答引用检查只识别 `JP`、`ZT` 编号，漏掉新论文、电子书和论坛编号。现检查通用方括号编号与本轮上下文的一致性，直接显示缺失、未知或匹配状态，并提供按编号回查原文的按钮。

本地原件入口只返回公开包中已接收的原件，每次核对散列；未知文件、排除项、路径越界及原件变化均拒绝。
PDF 链接保留页号；电子书保留章节或字符定位。该入口不提供任意本地文件，也不把原件加入 Pages 构建目录。

## 实测边界

首轮真实模型曾把 `B03-00002` 写成 `王03-00002`，检查器识别了错误。随后补充逐字复制编号的提示和显式失败提示，
复测正确引用了原编号。失败记录仍留在本地，没有改写或删除，也没有承诺模型以后不会再写错。
复测回答虽然引用正确，但把 waistcoat 生硬写成“腰coat”；模型回答仍须核对表述和原文，不能直接当作讲义。

向量检索可运行不等于相关性评测通过：合并库查询 `a rabbit carrying a watch` 时，精确余弦与近邻首位来自福尔摩斯语料；
`Rabbit watch` 的混合检索首位为《爱丽丝》相关片段。未据此宣称召回率或答案准确率。
采用固定 MiniLM 的 q8、mean、384 维、L2 归一化，最多编码前 512 tokens；保留全文不意味着模型编码了全部长文本。

D14–D20 等本机外部应用和保存案例仍使用原课堂语料，D01 导入不会自动重建它们的库；页面已明确提示。
论坛核验只覆盖入选标题摘要和已有回复，不包括完整源帖及后续评论；正文及对应向量继续仅本地保存。
本次没有重新联网核验所有外部来源可访问性，来源网站链接已核对，离线原件按先前出处审计的散列回查。

## 复现与合并建议

使用 `local/prepare-import-vectors.mjs`，指定已下载模型目录、JSONL 输入目录与新的输出目录；不触发下载，不覆盖既有准备结果。
再用 `scripts/check-week03-import-browser.mjs` 指定向量目录、输出目录和 Playwright 模块，`--generation` 才会调用本机生成模型。
配套模型要求与命令示例见 [本地预计算说明](../../local/PRECOMPUTE.md)。

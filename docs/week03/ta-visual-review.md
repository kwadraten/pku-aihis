## 发现与已修复

1. **D21 比较基线不一致，并越过语料范围。** 原来的初始候选按 BM25，Rocchio 的“更新前”却按余弦；选定章太炎范围后更新仍检索全库。现将初始与更新统一为同一查询模型、同一余弦度量、同一语料范围。相关判断移到每条候选旁，参数放在列表前；参数尚未执行时明确保留上次结果。查询向量异步返回后检查查询轮次与语料版本，旧结果不写回图形。
2. **D07 曲线随参数缩放纵轴，可能掩盖数值变化。** 现固定纵轴，加默认参数的灰虚线作为参照；解释 tf、L、avgL 的含义以及短段补偿、长段惩罚。蓝线和当前点随 k1、b 变化。
3. **D09 各卡片的条形尺度不同，缺席一路不显式出现。** 现前三候选使用统一尺度，各自显示关键词和向量两路；缺席贡献明确为零。c 更新时同步更新排序与原始融合记录。
4. **D12 可出现 M 大于 efConstruction。** 提高 M 时同步抬高过小的建图探索值，并显示规则，防止控件名义值与可行配置脱节。
5. **D24 只统计日志条数，难以区分提议与执行。** 现从实际 `model_proposal` 与 `tool_result` 记录生成逐轮时间线，分别列出模型提出的查询/片段 ID、工具实际返回的候选或正文长度，并显示结束、预算用尽或失败事件。教学箭头明确标为教学拆解，不是运行轨迹。
6. **工具页保存的运行数据仍是一整块 JSON。** 对已有 `results` 记录增加标题、片段 ID、分值、页码和原文卡片，分清保存的实跑与本次返回；完整请求仍可展开。未运行工具仍保留实际状态说明。
7. **D30—D32 分值含义不够明显。** D30 按去重查询词项计数并列出命中词，不把它显示成语义相似度。D31/D32 增加固定 −1 至 1 的余弦刻度，明确“不是准确率”。无命中显示回查提示。
8. **起始状态、投屏与窄屏细节。** D06 初始即采用可执行范例和对应替换，保留随机、复制、捕获高亮；匹配偏移标为 UTF-16。D05 注明稠密图只画前 100 个坐标、计算用全部 384 维。D04 将重复 JSON 折叠。提高机制说明和环节按钮字号，取消机制面板圆角；390 像素界面取消面板内部限高，使用整页滚动，防止图形藏在嵌套小滚动区。

## 边界与接续

本轮没有扩大史料库，也没有重新宣称 OCR 已达到定本质量。33 页结构均覆盖，但 D14—D20、D23、D25—D27 的本机应用体验仍须在阶段三安装后再次按实际服务返回核验。已保存候选卡只呈现有运行记录的数据。RRF 没有运行模型重排；HNSW 没有记录内部访问路径；视觉相似不是字形定读；Rocchio 是数学反馈，不是模型理解了史学判断。

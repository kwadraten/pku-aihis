# 助教第二周实际演示入口与教案

依据 `slides-src/src/index.html` 的实际使用，而不是组件目录数量；原文件散列见仓库 `docs/ta-source-baseline.json`。入口只有下列五页。

| 实际页 | 教案位置 | 可学习的对应方式 | 不应误学的部分 |
|---|---|---|---|
| s01-cover | 课程开场 | 标题、周次、学习方向构成课程入口 | 不能把未使用的组件算作覆盖内容 |
| s02-api-setup | 操作环境前提 | 先使请求能够发生，再观察模型流程 | 原例LocalStorage保存密钥不沿用到公开课堂页 |
| s04-request-pipeline | 1.1 请求与响应 | 同一次实际请求同步显示交互界面和事件路径 | 预设动画与真实响应分开 |
| s08-tokenizer-demo | 2.1 Token与表示 | 输入文字后显示词项与表示，建立文字到数据的桥梁 | 此页是固定词表贪心匹配、512维特征哈希，不能解释成训练所得嵌入 |
| s16-real-agent-harness | 3.1与3.1.1—4 | 实际工具循环显示调用、观察与下一步 | V不是独立史实验证器；轨迹不是模型内在思维 |

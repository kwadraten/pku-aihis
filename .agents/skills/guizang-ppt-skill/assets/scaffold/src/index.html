分词的核心数学约束

  • 词表上限 $V$：现代大模型（如 Qwen2.5、LLaMA 3）词表通常在 128k ~ 152k 之间。
  • BPE（字节对编码）：贪心合并高频相邻字节对，平衡稀疏生僻字与高频词组。
  • 汉字多字节惩罚：UTF-8 下每个汉字占用 3 字节，劣质分词器会导致中文字元极度膨胀。

Softmax 缩放数学原理

语言模型最后一层输出原始分数 (Logits) $z_i$，通过带温度参数 $T$ 的归一化指数函数映射为概率： 

P(w_i) = exp(z_i / T) / Σ_j exp(z_j / T)
  • $T \to 0$：极值差距被无限放大，退化为确定性 Argmax。
  • $T = 1.0$：模型预训练状态下的原始真实概率分布。
  • $T \gg 1.0$：分布趋于平坦均匀分布，随机性与幻觉急剧上升。
  • Top-P (Nucleus)：保留累积概率达阈值 $p$ 的最小词元集，斩断低频噪音长尾。

高维空间距离与方向

词元和句子通过嵌入层投射为稠密向量 $\mathbf{A}, \mathbf{B} \in \mathbb{R}^d$。衡量其语义亲疏通常不使用欧氏距离，而使用余弦相似度： 

cos(θ) = (A · B) / (||A||_2 · ||B||_2)
  • 夹角 $\theta \to 0^\circ$（余弦 $\to 1.0$）：语义方向高度一致。
  • 夹角 $\theta \to 90^\circ$（余弦 $\to 0.0$）：完全正交无关。
  • 语义算术：$\vec{v}_{\text{章太炎}} - \vec{v}_{\text{古文经学}} + \vec{v}_{\text{维新}} \approx \vec{v}_{\text{康有为}}$。

# AnythingLLM 本地实践

来源：https://github.com/Mintplex-Labs/anything-llm

桌面客户端把文档导入、嵌入器、检索器和生成器组织为工作区。

适用范围：桌面软件在本机运行；本页不伪装成AnythingLLM的嵌入界面。

## 建立工作区

先安装官方桌面客户端，选择本地模型/已授权服务和嵌入器。

```text
官网入口：https://anythingllm.com/desktop
工作区：week03
先记录应用版本、嵌入模型与生成模型。
```

观察：界面、模型和数据服务不是同一层。

## 导入与处理

导入准备好的小型带出处文本，观察切分和向量写入；完整PDF可在本机导入。

```text
记录：source_id / PDF页序 / 文章标题
设置：chunk size / overlap / embedding provider
```

观察：切块有没有丢掉页码或主体？模型改变后是否重建？

## 问答与引用

对同一问题查看检索到的上下文，再逐条回查回答引用。

```text
问题：哪些段落讨论宗教与道德的关系？
对照：删除关键文档后重新提问。
```

观察：回答是否随着可用证据改变？引用是否真支持论断？

## 运行与验证口径

网页步骤展示不是执行日志。仅在页面明确出现带版本和时间的运行结果时记为实跑。服务型工具在本地启动，GitHub Pages只提供前端。真实语料使用同一份带页码记录的JSON；模型及向量配置须兼容。完整OCR保留本机。

本仓库已准备 `assets/data/classroom-text.txt`，每段含ID、作者、PDF页、印刷页和校订状态。首次教学可下载该文件导入工作区；完整OCR继续保留本机。切块后若来源行被拆开，应调整大小/重叠或按ID分文件，不能把生成器附的任意页码当作原页定位。

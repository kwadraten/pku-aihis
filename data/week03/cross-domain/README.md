## 回查与复现

- `start_char` / `end_char` 是 `text_file` 中 Python Unicode 字符索引，左闭右开；不是字节或 JavaScript UTF-16 索引。
- 电子书另有 `raw_start_char` / `raw_end_char`，对应 UTF-8-sig 解码并统一换行后的原件。
- PDF 使用 1 起算的文件页，未将印刷页码与文件页混用；《理想国》按 Book I–X 定位。
- 从仓库根目录执行 `python3 scripts/package-week03-corpus.py` 检查完整性。
- 执行 `python3 scripts/package-week03-corpus.py --zip /tmp/week03-cross-domain.zip` 生成确定性 ZIP。
  ZIP 包括原件、导入数据、许可和核验清单；按仓库规范不将二进制 ZIP 重复提交 Git。
- 原始备料及抓取证据仍在教师本地目录；`scripts/prepare-week03-cross-domain.py --help` 说明重新核验、生成的输入接口。
  该步骤需要 PyMuPDF；验证和打包仅使用 Python 标准库。
